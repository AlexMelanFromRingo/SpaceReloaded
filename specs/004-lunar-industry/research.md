# Research: Лунная индустрия (сводка решений)

Подробности и источники: [research-physics.md](research-physics.md) (физика),
[research-api.md](research-api.md) (MC 26.2 API, проверено javap).

## R1. Требуемая скорость катапульты
- **Decision**: v_req = √(v_esc² + v∞²), v∞ обращается из табличного Δv 003 (перелёт из парковочной орбиты) по патч-коникам; Луна → орбита Земли ≈ 2517 м/с.
- **Rationale**: согласовано с таблицей 003 (822 м/с из НОО Луны ↔ тот же v∞ ≈ 832 м/с); один источник правды — датапак; работает для аддон-тел.
- **Alternatives**: √(gR) + Δv (≈ 2500, физически неверная сумма скоростей); отдельная таблица скоростей катапульты (дублирование данных).

## R2. Кинематика рельса
- **Decision**: v² = 2·Σaᵢ·Lᵢ, тиры 1000 g / 3000 g; рельс 324 / 108 блоков для Луны.
- **Rationale**: точное решение для кусочно-постоянного ускорения; О'Нил закладывал ~1000 g для сыпучих грузов; длины укладываются в игровые масштабы (≤ 400 секций, 25 чанков).
- **Alternatives**: минимум ускорения по секциям (грубее, наказывает смешанные рельсы нефизично); три тира (избыточно для 004).

## R3. Масштаб энергии
- **Decision**: 1 E = 15 кДж (масштаб, неявно заданный пушкой), η = 0.85, капсула 100 кг + 2 кг/предмет.
- **Rationale**: единый масштаб «кинетических» механизмов мода; пустая капсула ≈ 25 тыс. E, полная ≈ 1.1 млн E — заметная, но достижимая инфраструктура (4–5 конденсаторов на полную).
- **Alternatives**: реальный 1500 кг на блок реголита (выстрел в сотни млн E — неиграбельно); масса предмета из таблицы по типу (сложно, нет в моде).

## R4. Атмосфера
- **Decision**: запрет по напору на срезе (Земля 3.9 МПа > 1 МПа) и по тепловому потоку Саттона–Грейвса (Марс).
- **Rationale**: укороченные шкалы высот мода занижают столб атмосферы ~75× — интеграл торможения давал бы ложное «можно»; критерий на срезе консервативен и честен.
- **Alternatives**: численный полёт капсулы через `DragBody` (неверный результат из-за масштаба шкал высот).

## R5. Ловушка
- **Decision**: гауссово рассеивание σ = 0.5 (покрытие) / 10 (без), P = 1 − exp(−r²/2σ²), r = r₀ + k·√(секций сетки).
- **Rationale**: та же модель точности, что у пушки (покрытие = навигация); площадь сетки → эквивалентный радиус круга.
- **Alternatives**: равномерный круг рассеивания (менее физично); гарантированный приём (нет хардкора, нет роли спутников).

## R6. MRE
- **Decision**: блок реголита → 150 ед. O₂ за 1600 E, Fe-пыль 1, Ti-пыль 20 %, шлак 1; 200 тиков/цикл.
- **Rationale**: масштаб от электролизёра мода (лёд → 300 ед. за 800 E); реальные ~21 кВт·ч/кг O₂ и 20–30 % извлечения дают соотношение «реголит вдвое дороже и вдвое беднее льда» (research-physics §4).
- **Alternatives**: восстановление ильменита водородом (1–5 % выхода — неиграбельно, требует водорода).

## R7. Спечённый реголит
- **Decision**: взрывостойкость 40 (камень 6, обсидиан 1200, порог метеорита 100) — защищает толщиной, а не абсолютно.
- **Rationale**: реальная защита — масса над головой (~300 г/см²); обсидиан остаётся «бункерным» тиром.

## R8. Лавовые трубки
- **Decision**: детерминированная полилиния на регион 128×128, chunk-local вырезание в Feature; укрытие +17 °C (LRO Diviner); игровые размеры 7–13 × 5–9.
- **Rationale**: Feature не может писать далеко от своего чанка; детерминированная функция региона сшивается по чанкам без состояния; кастомный WorldCarver — больше риска API без выигрыша.
- **Alternatives**: шаблон .nbt (ограничен 3×3 чанками); кастомный carver.

## R9. Рендер и анимация
- **Decision**: BER на казённике рисует волну/вспышку/салазки по синхронизированным тикам; `shouldRenderOffScreen`, `getViewDistance 256`; реактор — BER окна + LIT.
- **Rationale**: единственный рендерер на структуру, без тиков на клиенте; API проверен (research-api §1–2).
- **Alternatives**: блок-состояния «горит» на каждой катушке (сотни обновлений блоков на выстрел — нарушает бюджет).

## R10. Звуки
- **Decision**: синтез sox → ogg утилитой `tools/gen_sounds.py`, исходник в репозитории (MIT).
- **Rationale**: свои звуки без стороннего контента и лицензий; ресурс-пак заменяет.
- **Alternatives**: ванильные файлы под новыми событиями (не «свои»).

## R11. Достижения
- **Decision**: `minecraft:impossible` + программная выдача из серверных событий.
- **Rationale**: события (выстрел, приём, O₂) не являются получением предмета; кастомный CriterionTrigger — больше кода без пользы.
