# Quickstart: проверка фичи 004

Предусловия: `export JAVA_HOME=~/.sdkman/candidates/java/25.0.3-tem`.

1. Ядро: `./gradlew :core:test` — новые тесты `core.industry.*`, `core.worldgen.*` зелёные (v_req Луны ≈ 2517 м/с, доля приёма совпадает с формулой).
2. Сборка: `./gradlew build`.
3. Стенд: `timeout 570 ./gradlew :mod:runClientGametest` (DISPLAY=:0) — сценарии `testMassDriver`, `testMassCatcher`, `testRegolithReactor` проходят вместе со старыми.
4. Ручной плейтест (креатив, новый мир):
   - `/execute in spacereloaded:moon run tp @s 0 120 0`; найти провал лавовой трубки (≤ 8×8 чанков), спуститься — достижение «Под поверхностью»; Jade/телеметрия показывает +17 °C под крышей.
   - Найти место крушения зонда, открыть бочку — добыча.
   - Построить казённик + 110 сверхпроводящих катушек + 5 конденсаторов + creative_power; ПКМ — отчёт (v_max ≥ 2517); на орбите Земли поставить ловушку с сеткой 5×5, привязать программу, вложить программу в казённик; капсула + груз; Sneak+ПКМ — волна, вспышка, возврат салазок, звук; через 30 с груз в ловушке.
   - Реактор 3×3×3: реголит + баллон → свечение окна, гул; шлак → электропечь → спечённый реголит.
5. Документация: README/GUIDE/сайт содержат таблицу длин рельса и энергий.
