# Implementation Plan: Тяжёлая индустрия

**Branch**: `008-heavy-industry` | **Date**: 2026-09-24 | **Spec**: [spec.md](spec.md)

## Summary
Шесть мультиблоков по образцу реальных систем: стойка жизнеобеспечения (OGS + Sabatier + CDRA +
WRS МКС), реактор деления Kilopower с ураном и каскадом центрифуг, криогенная воздухоразделительная
колонна Линде, дуговая сталеплавильная печь, антенна дальней связи DSN. Физика — ядро
`core.{eclss, nuclear, cryo, metallurgy, comms, thermal}` с JUnit; мод — контроллеры на общем
`FormedStructure` 005 и новый общий слой анимации: цели движения приходят событием, клиент ведёт
части пружиной с ограничением скорости привода. Модели — генератор `tools/gen_008.py` цельными
объёмами (как `gen_gears.py`), шаблоны — датапак.

## Technical Context
**Language/Version**: Java 25, Fabric Loom 26.2 (официальные имена Mojang), JUnit 5.
**Primary Dependencies**: Fabric API, Team Reborn Energy; клиент — BlockEntityRenderer + BlockModelRenderState.
**Storage**: NBT блок-сущностей контроллеров (состояние реактора, плавки, стойки), компоненты
предметов (обогащение и выгорание топлива, остаток электрода, чистота газа), SavedData связи
(`SpaceNetworkState` — наземные антенны).
**Testing**: JUnit ядра против эталонов research-design §1–6; клиентский стенд `runClientGametest`
(сценарии US1–US6 + кадры README анимаций).
**Performance**: контроллеры тикают только собранные: реактор — каждый тик (кинетика с шагом 0.05 с,
аналитический шаг экспоненты, O(1)), остальные — раз в секунду. Анимация — чистая функция времени и
синхронизированной цели на клиенте, пакет только при смене цели/режима.
**Constraints**: сервер авторитетен; клиентская анимация не влияет на физику.
**Scale**: 6 шаблонов, ≈ 35 новых блоков/предметов, 7 классов ядра.

## Ключевые решения
- **D80 Общий молот.** Новый интерфейс `HammerTarget { boolean hammer(ServerLevel, ServerPlayer) }`;
  `EngineerHammerItem` вызывает его у любого BE (4 старых контроллера реализуют интерфейс) — вместо
  цепочки `instanceof`. `FormedStructure` 005 без изменений.
- **D81 Анимация.** Клиентский `SmoothDrive` (в `client/render/anim/`): состояние (позиция, скорость)
  хранится в клиентском экземпляре BE; в `extractRenderState` шаг критически демпфированной
  пружины к цели с ограничением |v| ≤ v_привода по реальному времени кадра. Цели и режимы —
  синхронизируемые поля BE (`sendBlockUpdated` по событию, как у казённика катапульты). Вращения —
  фаза `ω·t` от синхронизированного момента (как валы 005). Свечение — `GlowGeometry` /
  `RenderTypes.lightning()` с цветом `core.thermal.Blackbody.rgb(T)` и яркостью ∝ (T/T_ref)⁴.
  Подвижные части — модели-блоки `registerNoItem` из `gen_008.py`.
- **D82 Стойка.** Шаблон: ключ `eclss_controller` в стене зоны, рама `eclss_rack_frame` 4×3 с
  четырьмя гнёздами `#spacereloaded:eclss_socket` (модули или глухая панель). Контроллер после
  сборки читает, какие модули в гнёздах. Газ — `LifeSupportState.contribute` (источник O₂, удаление
  CO₂) раз в секунду; баланс — `EclssBalance`. Вода — слот: лёд по таблице масс (9.17 кг/блок), ведро воды — 1000 кг (как у
  гидролотка 007: ведро = блок воды = 1 м³); H₂ — внутренний буфер. CH₄ —
  в соседний топливный бак как метанокс при O/F = 3.6, O₂ берётся из соседнего газового баллона;
  без баллона — сброс (как МКС).
- **D83 Реактор.** Вертикальная сборка как у Kilopower (зона внизу, радиатор-«зонтик» наверху):
  ключ `control_rod_drive` (привод и пульт, в корпусе с окном — виден ход штока), над ним
  `reactor_core` в кольце `beo_reflector` (3×3), выше тепловые трубы, ряд из 4 гнёзд
  `#spacereloaded:reactor_power_slot` (`stirling_convertor` или заглушка), затем повтор сегментов
  радиатора вверх (1–12). Кинетика и тепло — `PointKinetics` + `ReactorThermal` каждый тик;
  стержень — цель от игрока (экран/редстоун), позиция ведётся сервером со скоростью привода
  (физика), клиент сглаживает. Энергия — в сеть (`MachineBlockEntity`). Расплав → блок
  `reactor_core` в состояние `damaged=2`, отказ.
- **D84 Топливо.** Руда `uraninite_ore` (Земля, y −64…−16, редкие жилы; богатая урановая смолка,
  **решение**), цепочка на существующих машинах 006: химреактор (выщелачивание H₂SO₄ → жёлтый кек;
  UO₂ + 4HF → UF₄; UF₄ + F₂ → UF₆), F₂ — электролизный стек из HF с электролитом KHF₂ (поташ — зола
  ламинарии, `kelp_ash` из печи: исторический источник калия). Каскад: ключ `cascade_controller`,
  повтор `gas_centrifuge` 1–40; обогащение `Enrichment.product(N, α = 1.3)`, материальный баланс
  F = P + W с отвалом 0.25 %. Предмет `uranium_hexafluoride` несёт компонент `enrichment`;
  металл — восстановление в электропечи; сплав U-Zr (цирконий — `zircon` из песка, отсев в
  дробилке); корзина `fuel_basket` (масса U-235 → запас реактивности).
- **D85 Колонна.** Ключ `asu_sump` (испаритель) внизу, повтор `asu_tray` вверх 3–40, сверху
  `asu_condenser`; сбоку `asu_heat_exchanger` и `asu_compressor` — кинетическая машина
  (`KineticBlockEntity` с нагрузкой `NodeLoad`), мощность вала → поток воздуха. Работает, где
  профиль тела `breathable` или атмосфера содержит азот/аргон (Марс: CO₂-атмосфера — колонна
  выделяет только буферные газы, **решение**: на Марсе нет O₂ в воздухе — колонна не даёт O₂).
- **D86 Печь.** Ключ `eaf_controller` (трансформатор) сбоку корпуса 3×3×3 `eaf_shell`, свод
  `eaf_roof` с тремя гнёздами электродов (предмет `graphite_electrode` с прочностью = масса).
  Фазы: `OPEN → CHARGED → MELT → REFINE → TAP`. Анимации: свод (поворот вокруг шарнира), электроды
  (ход вниз/вверх), дуга (мерцание), наклон всего корпуса при сливе (BER рисует корпус как
  модель-часть, сами блоки не двигаются: в собранном виде блоки корпуса — «невидимый» formed-вариант,
  а весь вид рисует BER — как у IE).
- **D87 Антенна.** Ключ `dsn_controller` (приёмник), опора `dish_mount`, повтор колец
  `dish_panel` (радиус 1–8 блоков → D = 2r м). В собранном виде панели скрыты (formed = невидимый
  вариант), тарелку целиком рисует BER как одну поворотную модель с азимутом и углом места
  (сопровождение цели). Цель — тело из списка профилей; положение на небе — из игрового времени и
  фазы (Луна) — **упрощение**. Бюджет линии — `LinkBudget`; `SpaceNetworkState` получает запись
  наземных антенн (измерение цели → лучшая скорость); `Logistics.coverageSatisfied` учитывает её;
  `OrbitalImages.develop` ждёт передачу.
- **D88 Руководство.** `EngineerManualScreen`: список страниц с прокруткой (колесо и кнопки ▲▼).
- **D89 Генератор.** `tools/gen_008.py` (данные: шаблоны, теги, рецепты, лут, массы, блокстейты,
  модели цельными объёмами), `tools/gen_textures_008.py`, `tools/lang_008.py`, звуки — в
  `tools/gen_sounds.py`.
