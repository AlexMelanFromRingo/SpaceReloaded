# Quickstart 005

1. `./gradlew :core:test` — kinetics/industry/multiblock тесты зелёные.
2. `./gradlew build`; стенд `DISPLAY=:0 timeout 570 ./gradlew :mod:runClientGametest` — сценарии трансмиссии, среза, пресса с маховиком, стека/колонны, качества двигателя, взрыва.
3. Вручную: мотор + сталь + шестерни 2:1 → Jade показывает 1500 → 750 об/мин; пресс с маховиком и без; молот по электролизёру с 7 ячейками; руководство инженера — страницы мультиблоков; цепочка сопла → двигатель → скан-отчёт с качеством.
