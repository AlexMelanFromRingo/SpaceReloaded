# Контракт: новые поля конфига `spacereloaded.json`

Все поля — публичные примитивы `SpaceReloadedConfig` (Gson), значения по умолчанию ниже, диапазоны проверяются в `validate()` (нарушение — исключение с русским сообщением, как у существующих полей). Старые ключи `cannonDragCoeff`, `meteorDragCoeff` (линейная модель) удаляются; их наличие в старом файле игнорируется Gson.

| Поле | Тип | По умолчанию | Диапазон | Смысл |
|---|---|---|---|---|
| `attitudeMaxDeg` | double | 45 | [5, 60] | Предел командуемого наклона (граница модели малых углов) |
| `attitudeRateDegPerSec` | double | 30 | [1, 180] | Скорость роста/возврата командуемого угла при удержании/отпускании клавиши |
| `rocketDragCoefficient` | double | 0.5 | [0, 3] | C_d ракеты (блочная ракета как тупое тело) |
| `cannonRodDragCoefficient` | double | 0.1 | [0, 3] | C_d вольфрамового лома (заострённое тело) |
| `cannonRodAreaM2` | double | 0.03 | (0, 10] | Площадь сечения лома, м² (Ø ≈ 0.2 м) |
| `meteorDragCoefficient` | double | 1.0 | [0, 3] | C_d метеорита (неправильное тело) |
| `meteorAreaM2` | double | 1.0 | (0, 50] | Площадь сечения метеорита, м² |
| `reentryHeatIndexThreshold` | double | 6.0e6 | (0, ∞) | Порог индекса нагрева √ρ·v³ (≈ 176 м/с у поверхности Земли) |
| `reentryHeatDamage` | float | 2.0 | [0, 40] | Урон экипажу за интервал при превышении порога без капсулы |
| `reentryHeatIntervalTicks` | int | 20 | ≥ 1 | Интервал урона нагрева (делитель тик-цикла — обязателен ≥ 1) |
| `maxDynamicPressurePa` | double | 35000 | (0, ∞) | Порог скоростного напора для предупреждения в скан-отчёте |
| `stageSeparationImpulseNs` | double | 3000 | [0, 1e6] | Импульс раздвигания частей при отделении (Н·с); Δv частей = J/m |
| `stageDebrisMaxTicks` | int | 6000 | ≥ 20 | Предельное время жизни обломка ступени (предохранитель от вечного падения) |
| `cannonGuidedSpreadBlocks` | double | 0.5 | [0, 4] | Радиус рассеивания наводимого лома (≤ 1 блока по спеке) |
| `cannonUnguidedSpreadBlocks` | double | 10 | [0, 64] | Радиус рассеивания без спутникового покрытия |

Ограничения профиля тела (датапак, проверяются при загрузке реестра, см. datapack.md): `atmosphere_density ∈ [0, 50]`, `scale_height ∈ [1, 100000]`.
