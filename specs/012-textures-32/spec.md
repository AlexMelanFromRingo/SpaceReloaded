# Feature Specification: Текстуры 32×32

**Feature Branch**: `012-textures-32` · **Created**: 2026-09-29 · **Status**: Draft

**Input**: «Обнови текстуры — освежи, сделай проработаннее и качественнее. У батареи шкала сверху —
некрасиво и несимметрично. А у составной антенны наклон возможен в сторону, куда крепление физически
не должно позволять». Ответы: разрешение 32×32, все текстуры сразу.

## User Scenarios & Testing *(mandatory)*

### US1 — Единый стиль 32×32 (P1)
Все текстуры блоков и предметов мода — 32×32, свет сверху-слева, палитры материалов, симметричные
детали, мягкое зерно без ряби. Старая узнаваемость (цвета веществ, маркировка баллонов) сохранена.
**Test**: `python3 -m tex32.build --check` — покрыто N из N; каждая PNG 32×32 (анимации — 32×32·k).

### US2 — Батарея (P1)
Боковая грань — окно уровня заряда по центру (сегменты снизу вверх), верх — клеммы «+»/«−»,
низ — опоры. **Test**: модели батареи — `cube_bottom_top`, шкалы на верхней кромке нет.

### US3 — Опора антенны DSN (P2)
Щёки вилки стоят по сторонам оси цапф (север/юг), тарелка качается только к востоку/западу —
туда, куда механизм позволяет. **Test**: ось цапф модели опоры совпадает с осью наклона рендера (Z).

## Requirements
- **FR-1200** все текстуры рисуются кодом (`tools/tex32`), руками PNG не правятся; сборка детерминирована.
- **FR-1201** правила стиля — `tools/tex32/STYLE.md`.
- **FR-1202** детали кладутся в видимые uv-области моделей.
- **FR-1203** анимированные жидкости — кадры 32×32, бесшовные и зацикленные.
- **FR-1204** цвета карты (`gen_map_colors.py`), сайт и снимки README пересобраны по новым текстурам.

## Success Criteria
- **SC-001** покрытие 100 %; сборка и полный стенд зелёные.

## Assumptions
- Модели используют uv в 16-единичном пространстве — переход на 32×32 их не меняет.
