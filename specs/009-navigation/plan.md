# Implementation Plan: Навигация

**Branch**: `009-navigation` | **Date**: 2026-09-25 | **Spec**: [spec.md](spec.md)

## Summary
Небесная механика вместо окна-выключателя: кеплеровы эфемериды JPL, задача Ламберта и цена перелёта
на дату отлёта (ядро `core.orbit`), единый календарь мира. Мод: сервис цены перелёта для перехода
ракеты, HUD, планировщика миссий и карты; карта полётов с ценами рёбер и экран «свиной отбивной»;
гиперспектральный спутник с картой минералов открытой поверхности; георадар ровера с радарограммой.
Данные — датапак (орбиты в профилях, сигнатуры минералов, диэлектрики), генератор `tools/gen_009.py`.

## Technical Context
**Language/Version**: Java 25, Fabric Loom 26.2, JUnit 5.
**Primary Dependencies**: Fabric API; клиент — Screen, MapItem (запертые карты 007).
**Storage**: профили планет (реестр, синхронизируется клиенту); `SpaceNetworkState` — число
гиперспектральных спутников; компоненты предметов — заказ карты минералов (как `IMAGE_ORDER`),
трассы радарограммы (массив байтов); NBT ровера — буфер трасс и признак георадара.
**Testing**: JUnit ядра против эталонов research-design §3–4 (InSight, окна 2018–2044, t = 2d√ε/c);
стенд `runClientGametest`: сценарии US1–US4 и кадры README (карта Δv, «свиная отбивная», карта
минералов, радарограмма).
**Performance**: цена перелёта — ≈ 40 решений Ламберта (бисекция, ~100 итераций) на дату, кэш по
полусуткам астрономического времени; поиск ближайшей доступной даты — шаг 2 сут по синодическому
периоду (~390 дат) только при отказе старта. «Свиная отбивная» — 64 × 40 решений однократно при
открытии экрана. Карта минералов — фоновый поток, как снимок 007. Георадар — столбец ≤ 48 блоков на
каждые 0.5 м пути.
**Constraints**: сервер авторитетен; клиент считает цену по тем же профилям (реестр синхронизирован)
только для отображения.
**Scale**: 4 класса ядра (`Ephemeris`, `Lambert`, `InterplanetaryTransfer`, `GameCalendar`) +
`SpectralMapping`, `GroundRadar`; ≈ 6 новых предметов; 2 экрана.

## Ключевые решения
- **D90 Календарь.** `GameCalendar.day(tick) = 6647 + tick / 24000 × 130` (сут после J2000, 14.03.2018).
  `OrbitalImaging.ASTRO_COMPRESSION` и ДСС пользуются им; долготы ДСС — из `Ephemeris` (проекция на
  эклиптику), Луна — по фазе, как в 008.
- **D91 Профиль.** `TransferSpec` получает необязательные `orbit` {a_au, e, i_deg, node_deg,
  peri_deg, mean_lon_deg}, `mu`, `aerocapture`. Орбита Земли: элементы Земли, μ⊕, R 6371 км, парковка
  200 км, аэрозахват; Марс: элементы Марса, μ♂, аэрозахват; пояс: Церера, μ 6.26·10¹⁰, без захвата.
  Поля окна-расписания уходят из `mars.json` (остаются в кодеке для датапаков).
- **D92 Сервис цены.** `planet/TransferCosts.cost(access, from, to, tick)`: если у обоих концов есть
  орбита и они разные — `InterplanetaryTransfer.best` на `GameCalendar.day(tick)`, иначе таблица;
  × `transferDeltaVScale`. Кэш (from, to, tick / 92) на 256 записей. Вызовы: переход ракеты,
  `nextHopCost` (HUD), `MissionPlanning`, катапульта (таблица Луны — без изменений), карта.
  `TransferWindows.hasWindow` ложно для тел с орбитой.
- **D93 Бюджет вместо окна.** Отказ беспилотного старта `WINDOW` заменяется на `BUDGET_TODAY`:
  «сегодня X м/с, есть Y; хватит через N сут» (`TransferCosts.nextAffordableTick`) или «в этом периоде
  не хватит». Грузовая линия в АВТО уже повторяет попытку — уходит в день, когда цена ≤ бюджета.
- **D94 Карта Δv.** `PlanetMapScreen`: подпись цены на каждом ребре (сегодня), в панели — минимум за
  период и дни до него, Δv ступеней пилотируемой ракеты (из синхронизированного отчёта). Кнопка
  «Окна» открывает `PorkchopScreen`: слева Δv(дата) на синодический период (отметки «сегодня»,
  «минимум»), справа тепловая карта 64 × 40 «дата × время полёта» с изолиниями по 0.5 км/с.
- **D95 Гиперспектральный спутник.** Предмет `hyperspectral_satellite` (полезная нагрузка, как
  `imaging_satellite` 007: беспилотный рейс ставит его на орбиту цели), `SpaceNetworkState.spectralSats`.
  Предмет `mineral_map` (пустой): ПКМ по ЦУПу заказывает карту минералов (Sneak — масштаб); ожидание —
  пролёт, как 007 (передача по ДСС — 240 каналов на пиксель); проявление — запертая карта: фон —
  рельеф в сером, пиксели минерала — его цвет. Легенда — в подсказке (минералы и доли карты).
  Местность — загруженные чанки и сохранённые на диск (`SavedSurface`: region-файлы в фоновом
  потоке; это улучшает и снимок 007), неразведанная — рельеф генератора. Приёмник спектрометра —
  PbS из новой руды галенита (кремниевая линейка 007 слепа дальше 1.1 мкм).
- **D96 Сигнатуры.** Датапак `spacereloaded/spectral/<id>.json`: `{"blocks": [id | #тег], "mineral",
  "map_color", "band_um"}`. Минерал пикселя — доля верхних блоков пикселя ≥ 25 %. Минералы без полос в
  таблицу не входят.
- **D97 Георадар.** Предмет `ground_radar`: ПКМ по роверу ставит радар (как батарею 007), Sneak+удар
  снимает. Пока ровер едет с радаром и батареей, каждые 0.5 м — трасса: столбец ≤ 48 блоков под
  колёсами, среды по датапаку `spacereloaded/dielectric/<id>.json` `{"blocks", "epsilon",
  "loss_tangent"}` (по умолчанию: твёрдый блок ε 6, tan δ 0.02; воздух 1, 0; вода 80, 0.5). Ядро
  `GroundRadar.trace(layers)` → 128 отсчётов по 3 нс, амплитуда в дБ (Френель − затухание −
  расхождение 20·lg 2d), порог −60 дБ. ПКМ по роверу бумагой печатает `radargram` (до 256 трасс) и
  очищает буфер; ПКМ радарограммой — `RadargramScreen`.
- **D98 Достижения.** «Небесная механика» (перелёт к Марсу при цене ≤ 1.02 минимума периода),
  «Спектр» (проявлена карта минералов с найденным минералом), «Под грунтом» (радарограмма с
  отражением глубже 5 м).
- **D99 Генератор.** `tools/gen_009.py` (профили, сигнатуры, диэлектрики, рецепты, модели, достижения),
  `tools/gen_textures_009.py`, `tools/lang_009.py`.
