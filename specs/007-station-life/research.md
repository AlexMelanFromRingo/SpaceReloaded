## Решения автора (2026-09-24)
| Вопрос | Решение | Следствие |
|---|---|---|
| Шкала времени биологии | игровые сутки (×72) | CO₂ в 75 м³ — угроза через ~13 мин; урожай в игровых сутках |

| Ванильные грядки (по умолчанию) | не в газовом балансе | одна модель лотков, без тикеров |

## Решения плана
- **Динамика кольца не через сеть 005.** Сеть 005 закреплена за мир (реакция мотора уходит «в землю»),
  что для кольца — запрещённая «ручка гравитации». Кольцо — своя система с сохранением момента
  импульса: реактивная пара — двигатели обода (топливо) или противовращающиеся ступицы. Прочность —
  `ShaftStrength` 005.
- **Газ зоны — общий трекер с частицами 006?** Нет: разные ключи жизни (чистая комната может быть без
  экипажа), но общая математика `FirstOrderMix` в ядре.
- **Баллон маски** = 0.42 кг O₂ (1200 ед., единица за 10 тиков → 0.84 кг/игровые сутки, та же норма BVAD).
- **CO₂-предмет** = 1 кг (таблица масс 003 уже так считает).

## Проверки API 26.2 (javap по `minecraft-common.jar`)
- `Attributes.GRAVITY` + transient-модификатор — уже используется `PlanetEffects`.
- Сохранение по игроку — SavedData уровня Overworld (карта UUID → сутки), как `PodTransitState`.
- Карта-снимок: `MapItemSavedData` / `filled_map` — проверить при US5 (стретч).
- Сущность-транспорт — по образцу `RocketEntity` (пассажиры, синхронизация ввода).
