# Implementation Plan: Жизнь на станции

**Branch**: `007-station-life` | **Date**: 2026-09-24 | **Spec**: [spec.md](spec.md)

## Summary
Зона перестаёт быть «шкалой атмосферы 0..1 из энергии»: она хранит массы O₂/N₂/CO₂, экипаж дышит
по нормам NASA BVAD в игровых сутках, поглотители (LiOH, цеолит → Сабатье) держат CO₂, насос шлюза
откачивает тамбур по экспоненте, люк не открыть при перепаде. Оранжерея — гидропонные лотки с
культурами BVAD под небом или фитолампами, окислитель соломы замыкает углерод. Орбита становится
почти невесомой (0.02 g) с декондиционированием; кольцо даёт вес ω²r по высоте, Кориолис, баланс и
честную раскрутку. Ровер из деталей едет по механике грунта Беккера. Стретч — спутник-камера.
Физика — ядро `core.lifesupport`, `core.station`, `core.vehicle`, `core.orbit`; газ зоны — событийная
аналитика по образцу `CleanroomTracker` 006, без тикеров.

## Technical Context
**Language/Version**: Java 25, Fabric Loom 26.2 (официальные имена Mojang), JUnit 5.
**Storage**: SavedData уровня (`LifeSupportState`: газ зон, кольца), компоненты предметов (культура,
заряд батареи, кислород баллона в кг-эквиваленте), персистентные данные игрока (сутки невесомости),
NBT блок-сущностей (лотки, насос, поглотители).
**Testing**: JUnit ядра против аналитики; клиентский стенд `runClientGametest` — сценарии US1–US4.
**Performance**: газ зоны и кольцо — пересчёт только по событиям и по вычисленной метке ближайшего
пересечения режима; раз в секунду — сверка суммы источников (игроки/мобы в зоне: `Set.contains`);
Кориолис — каждый тик только для игроков внутри кольца (горячий путь, Set.contains).
**Constraints**: сервер авторитетен; клиент рисует HUD газа и вращение неба; ровер — сущность с
серверной физикой, клиент предсказывает ввод, как ракета 002.

## Ключевые решения
- **D70 Газ зоны** — `core.lifesupport.CabinAtmosphere`: массы O₂/N₂/CO₂, V, T → p, pᵢ; каждый газ —
  отрезок V·dc/dt = G − k·c (общий `FirstOrderMix`), регулятор O₂ держит уставку, пока есть запас.
  Мод: SavedData `LifeSupportState` (ключ — позиция контроллера зоны), события как у `CleanroomTracker`:
  пересчёт зоны, сверка источников раз в секунду, установка/снятие лотков, поглотителей, ламп; плюс
  плановая метка ближайшего пересечения режима (запас кончился, порог pCO₂, растения насытились).
- **D71 Наполнение из баков** — новый блок `gas_tank` (O₂ или N₂, кг, режим по первому газу),
  контроллер тянет газ из соседних баков до уставки 101 кПа / 21 % O₂; энергия идёт только на климат.
  Источники: электролизёр и реголитовый реактор отдают O₂ в соседний бак (сверх баллона); новый
  `air_separator` на планетах с воздухом (криоразделение, ≈ 0.4 кВт·ч/кг) даёт N₂ + O₂; сборщик
  атмосферы Марса даёт N₂/Ar. Зона на планете с атмосферой запирает окружающий воздух (не «бесплатно» —
  он уже внутри). Старые вакуумные зоны теряют бесплатный воздух (решение автора) — баллон маски
  спасает; телеметрия объясняет.
- **D72 Дыхание и эффекты** — `Metabolism`: 0.84/1.01 кг/сут на игрока, Клейбер для мобов, пороги
  pCO₂ 0.53/1/3/7 кПа и pO₂ 19.5/16/10 кПа → эффекты; `VacuumHazard` считает зону пригодной, только
  если давление и pO₂ в норме (иначе маска/урон как в вакууме). Баллон маски: 1200 ед. = 0.42 кг O₂
  (маска тратит единицу за 10 тиков: 0.84 кг/игровые сутки — та же норма).
- **D73 Поглотители** — блок `co2_scrubber` в стене зоны со слотом картриджа: `lioh_cartridge`
  (расходник, 0.75 кг CO₂, износ = поглощённая масса) или `zeolite_bed` (вечный, расход Q·η, энергия
  2 МДж/кг CO₂, выдаёт `carbon_dioxide` (1 кг = предмет) в соседний контейнер или реактор Сабатье).
- **D74 Шлюз** — `airlock_pump` в тамбуре регистрирует тамбур как свою зону (как контроллер);
  `HermeticHatchBlock.beginCycle` при насосе планирует тик на t = (V/S)·ln(p₀/p_стоп), газ насоса
  возвращается в соседнюю зону, остаток списывается; без насоса — весь газ тамбура. Интерлок:
  Δp по обе стороны люка > 1 кПа — люк не открывается; конфиг-опция защитного интерлока скафандра.
- **D75 Оранжерея** — `hydroponic_tray` (BE: культура, момент посадки, DLI, вода, удобрение),
  `grow_lamp` (над лотком, PPF 1.66 мкмоль/Дж, мощность по культуре ×72 и κ), `biomass_oxidizer`
  (солома/несъедобная биомасса + O₂ → CO₂). Культуры — датапак `spacereloaded:crops` (контракт). Урожай
  — интеграл при сборе; лоток сообщает зоне G_O₂/G_CO₂; точка компенсации CO₂ останавливает
  фотосинтез (режимная граница зоны). Ванильные грядки — не в балансе.
- **D76 Невесомость** — `earth_orbit` gravity 0.196 (0.02 g, «дрейф к полу», документировано);
  персистентные данные игрока: сутки в < 0.1 g → уровень декондиционирования; при g ≥ 0.3 g₀
  «Слабость» пропорционально, время в ≥ 0.3 g₀ снимает. Малая g орбиты честно удешевляет «подъём» с
  платформы в планировщике (Δv подъёма — доли м/с).
- **D77 Кольцо** — блок `spin_hub` (ось по горизонтали); сборка — связные блоки от ступицы (снимок и
  флудфилл в фоне, предел числа блоков, изоляция от мира), I и дисбаланс — `RotatingAssembly` по
  массам таблицы; своя динамика ω (не сеть 005): моменты от `rim_thruster` (топливо из соседнего бака
  сборки, m = L/(r·Isp·g₀)) или от `despin_motor` между двумя ступицами на одной оси (L_сумм = 0,
  энергия сети). Игроки в кольце: гравитация ω²·(y_ступицы − y_ног), Кориолис каждый тик, выход через
  обод — скорость ω·r; дисбаланс сверх `ShaftStrength` — разрушение ступицы. Небо вращается у клиента.
- **D78 Ровер** — сущность `RoverEntity` (1–2 места, отсек 9 слотов): детали `rover_chassis`,
  `rover_wheel` ×4, `nife_battery` (заряд E в компоненте), `rover_seat`; сборка ПКМ деталями по
  раме, разборка Sneak+удар возвращает детали. Физика — `Terramechanics` с грунтом тела из профиля
  планеты (`soil`: n, k_c, k_φ, c, φ, K); ступень ≤ 1 блока по среднему уклону колёсной базы.
  `rover_charger` заряжает батарею от сети с C/5.
- **D79 Съёмка (стретч)** — `imaging_satellite` (запись `SpaceNetworkState.imaging`), заказ в ЦУП,
  предмет `orbital_image` (filled_map) через T по ширине полосы и облёту; палитра — рельеф и типы
  поверхности, без подземных руд.
