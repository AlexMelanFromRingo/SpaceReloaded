# Data Model: 007

## ZoneGas (SavedData `lifesupport_state`, ключ — позиция контроллера)
| Поле | Тип | Смысл |
|---|---|---|
| mO2, mN2, mCO2 | double, кг | массы газов в момент t0 |
| t0 | double, игровые сутки | начало отрезка |
| volume | double, м³ | объём зоны |
| setpointKpa, setpointO2 | double | уставка регулятора (101 кПа, 0.21) |
| sources | G_O2, G_CO2 (кг/сут), k_CO2 (м³/сут поглощения) | действующие на отрезке |
| nextEvent | double | аналитическое время ближайшего пересечения режима |
Переходы: наполнение (из баков) → жилой режим → разгерметизация (истечение) → пусто.

## GasTank (BE)
газ (O2 | N2 | пусто), масса кг, ёмкость (по объёму 1 м³ при 20 МПа ≈ 260 кг O₂ — **оценка** плана).

## Scrubber (BE)
картридж: LiOH (поглощено кг из 0.75) | цеолит (Q м³/с, η); выход CO₂ (кг, дробь копится).

## AirlockChamber (BE насоса)
V тамбура, быстрота S, фаза цикла, потеряно кг.

## HydroponicTray (BE)
культура, момент посадки (игровые сутки), DLI источник (небо/лампа), вода, удобрение, накопленная
биомасса (интеграл при сборе).

## SpinAssembly (SavedData, ключ — ступица)
ось, центр, блоки (позиция, масса), I, дисбаланс Σm·r, ω, L, связанная противоступица.

## CrewState (SavedData Overworld, UUID)
сутки в < 0.1 g, уровень декондиционирования.

## Rover (сущность)
детали, масса, заряд батареи (E), отсек 9 слотов, скорость, курс.

## ImagingOrder (стретч, SavedData)
центр, масштаб, время готовности, измерение.
