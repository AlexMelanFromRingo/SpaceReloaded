# Implementation Plan: Материалы и электроника

**Branch**: `006-materials-electronics` | **Date**: 2026-09-24 | **Spec**: [spec.md](spec.md)

## Summary
Честная цепочка электроники от песка (нулевой тир — реле и прошивная память, как у Apollo;
кремний — карботермия, трихлорсилан, ректификация в колонне 005 по Фенске, осаждение, Чохральский
от вала 005, пила; фаб — литография в чистой комнате, выход годных e^(−D·A)) и материалы с честными
ЛТХ (флюорит, алюминий, литий из сподумена, никель по Монду, баки Al-Cu/Al-Li, суперсплав турбины,
монокремниевая панель). Химия — единый формат процессных рецептов, исполняемый настоящими машинами
каждого процесса (печь, электролизный стек, Сабатье, колонна, реактор Сименса, мокрый реактор,
электролиз расплавов); физика — ядро `core.electronics`, `core.materials`.

**Ревизия 2026-09-24 («без упрощений», запрос автора).** Сняты все упрощения первой редакции:
свёрнутая химия одного реактора → процессы по своим машинам (D60′); одна литографическая операция →
маршрут окисление/экспонирование/травление по уровням шаблона в трёх машинах (D65′); средняя
концентрация по трапеции → точный интеграл по отрезкам событий с накопленным ∫C dt (D64′);
Чохральский без тигля → расходный кварцевый тигель, лигатура, годная доля и хвост по Шайлю с
сохранением массы примесей (D62′); проверка места продуктов «как есть» → атомарная выдача с
партиями: смешение по массе примесей, дробный выход, разбиение по слотам, ожидание места вместо
выброса в мир (D60′); HF «из флюорита и HCl» → честная серная кислота из серы колонны; Холл–Эру
с криолитовой ванной и сгорающим угольным анодом рядом с MOE на инертном аноде.

## Technical Context
Java 25, Fabric Loom 26.2, JUnit 5. Хранение: компоненты предметов (`purity`, `wafer_step`,
`wafer_defects`, `mask_uses`, `guidance_tier`, `turbine_superalloy`), состояние блока двигателя
(`superalloy`), NBT блок-сущностей. Производительность: чистая комната без тикеров — вычисление
при обращении; станции тикают только в работе.

## Ключевые решения

- **D60′ Процессные рецепты** (`spacereloaded:chemical` + поле `machine`): до 3 реагентов, до 3 продуктов с
  `yield`, `energy`, `ticks`, `purity`/`keep_purity`, `oxygen`. Исполнитель `ChemicalProcess` общий: партия
  фиксируется на старте (ячейки стека — параллельные реакции), энергия равномерно, выдача атомарная,
  партии с чистотой смешиваются по массе примесей (`Purity.blend`), дробный выход копится по предмету.
  Машины: электропечь (карботермия → MG-Si + 2 CO, направленная кристаллизация 5N, Вёлер → P + шлак,
  второй выход), электролизный стек (хлор-щелочной: рассол → HCl + NaOH), Сабатье (трихлорсилан, Монд
  Ni 8 % с возвратом CO; окно машины), колонна (ректификация ТХС по Фенске, K = тарелки или 1 ступень
  куба), реактор Сименса (новый блок: ТХС + H₂ из льда → поликремний, HCl 95 %; эпитаксия SOS),
  химический реактор (серная кислота, HF + гипс, глинозём из глины с возвратом HCl, криолит, LiCl,
  эпоксид, фоторезист, рассол), реголитовый реактор (MOE глинозёма с O₂; Холл–Эру в криолите: энергия
  ×0.7, 0.45 кг C/кг Al, без O₂; анортозит → Al + Si + O₂ + шлак; LiCl → Li).
- **D62′ Чохральский**: загрузка 3 куска (7.8 кг), тигель — расходник, лигатура P/Al (64 дозы), годная доля
  Шайля → слитки Ø50 × 150 мм (0.69 кг), хвост по Шайлю (бор k = 0.8) — поликремний своей чистоты;
  нагреватель 36 000 E за вытягивание; срыв фронта (CV > 5 %) → мультикремниевый брусок.
- **D63′ Пила**: слиток на оправке режется по пластине (шаг 0.275 + 0.25 мм; длина — из массы и
  сечения), пыль пропила по массе; скрайбирование готовой пластины — Binomial(DPW, e^(−DA)).
- **D64′ Воздух**: `CleanroomTracker` (SavedData): отрезок (C₀, t₀, G, Q, V, q, C_out) + ∫C dt до t₀;
  подсос q = 30 м³/мин на точку утечки; источники — люди (стоит/ходит/скафандр) и работающие машины
  (дробилка 10⁸/мин); точная средняя за операцию — разность интегралов; счётчик частиц в течеискателе.
- **D65′ Маршрут пластины** (`WaferProcess`): на уровень шаблона — окисление (диффузионная печь, O₂) →
  экспонирование (станция литографии, шаблон 50 контактов, фоторезист на 16 пластин) → травление SiO₂
  плавиковой кислотой (травильная ванна, заправка на 16); последний уровень — напыление Al и травление
  щёлочью; дефекты операции = (d₀ + s·C̄/C₅)/3. Радстойкий шаблон — только на кремнии-на-сапфире.
  Эмиттер солнечных элементов — диффузия фосфора (моно ≥ 6N → 21 %).

Первая редакция (сохранена для истории):
- **D60 Химический реактор** (`ChemicalReactorBlock`, рецепт `spacereloaded:chemical`: `inputs` [≤2 Ingredient с количеством], `outputs` [≤2 стека], `energy`, `ticks`, `keep_purity`, `purity` (выходная чистота)). Рецепты: карботермия (шихта → MG-Si 2N + CO), трихлорсилан (MG-Si + HCl → ТХС), осаждение Сименса (ТХС → поликремний, чистота переносится), Монд (метеоритное железо + CO → никель + железная пыль), глинозём (глина + HCl → глинозём), Холл–Эру (глинозём + криолит → алюминий), HF (флюорит + серная кислота?) — без серы: флюорит + HCl → HF + CaCl₂ (упрощение), криолит (HF + глинозём + щёлочь), хлорид лития (сподумен-пыль + HCl), литий (LiCl, электролиз расплава), эпоксид (кероген: сланец + HCl), фоторезист (сланец + щёлочь), фосфор (костная мука + кремниевая пыль + уголь), тигель (кварц).
- **D61 Чистота** — компонент `purity` (float N9); колонна 005 поднимает чистоту ТХС до `Purity.afterColumn(N, K)`.
- **D62 Чохральский** — кинетическая машина (база станков 005): окно 10–20 об/мин на шпинделе (понижение от мотора), среднее |ω/ω_ном − 1| за операцию ≤ 5 % → монокристалл.
- **D63 Пила** — кинетическая машина: рецепты `spacereloaded:sawing` (слиток → 8 пластин + пыль); готовая пластина → кристаллы (`DieYield.sample`).
- **D64 Чистая комната** — `CleanroomState` на `SealedZone` (карта по id зоны): модули считаются, если граничат с внутренним объёмом зоны; G из игроков внутри (скафандр — меньше) и «грязных» машин (дробилка, пресс); наружная концентрация — по измерению; негерметичная зона = наружная.
- **D65 Литография** — `LithographyStationBlockEntity`: пластина (шаг < M шаблона) + фоторезист + травитель (щёлочь или HF) → шаг+1, дефекты += d₀ + s·C̄/C₅ (C̄ — среднее за операцию из двух точек CleanroomState), шаблон −1 использование.
- **D66 Тир программы** — компонент `guidance_tier` на программе; `RocketEntity.installProgram` переносит тир; `MissionPlanning` берёт запас 2 % для тира ≥ 2.
- **D67 Материалы бака** — отдельные блоки `aluminium_fuel_tank`, `al_li_fuel_tank` (класс FuelTankBlock, та же BE) с массой в `part_properties`; ядро `TankMaterial` проверяет таблицу.
- **D68 Суперсплав** — компонент `turbine_superalloy` у турбонасоса (переносится цепочкой из суперсплавного слитка); двигатель — свойство `superalloy`, тяга ×1.3 в резолвере.
- **D69 Анортозит** — реголитовый реактор: вход анортозит → алюминий + кремний + O₂ + шлак.
