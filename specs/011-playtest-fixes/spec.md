# Feature Specification: Замечания плейтеста 1.0.0

**Feature Branch**: `011-playtest-fixes` · **Created**: 2026-09-29 · **Status**: Draft

**Input**: отзыв тестера со скриншотами: «соединение шестерёнок под углом 90° в разных плоскостях не
работает», «статического трения нет», «из экрана выйти можно лишь по Esc, E не работает», «при
присоединении новой части вся сеть сбрасывает скорость», «моторчикам — настройку скорости»,
«батарея бы отдавала энергию соседним блокам».

## User Scenarios & Testing *(mandatory)*

### US1 — Шестерни под прямым углом (P1)
Две большие шестерни на перпендикулярных осях, сдвинутые по диагонали в плоскости обеих осей,
передают вращение 1:1 как коническая пара (венец с фаской 45°).
**Test**: мотор → большая (ось X) → большая (ось Y, сдвиг +1,+1,0): ω равны, сеть «работает».

### US2 — Сеть не сбрасывается при подключении (P1)
Новая деталь, присоединённая к вращающейся сети, получает скорость по сохранению импульса Σ I·r·ω;
сеть теряет лишь долю на разгон детали.
**Test**: маховик на 1370 об/мин + новый вал → скорость ≥ 97 % прежней.

### US3 — Трение и выбег (P1)
Сеть без привода выбегает с замедлением (трение подшипника по весу + воздух)/J и останавливается;
с места трогается только при моменте выше трения покоя (×1.5). Сеть не засыпает на выбеге.
**Test**: замедление маховика = расчётному ± 20 %.

### US4 — Экраны закрываются клавишей E (P2)
Экраны мода закрываются и Esc, и клавишей инвентаря; запоздалый ответ обновления не открывает
закрытый экран заново. **Test**: E закрывает экран состояния, экранов после — нет.

### US5 — Скорость мотора (P2)
Напряжение якоря 10–100 % кнопками экрана: ω₀ ∝ U, τ_st ∝ U, P_max ∝ U².
**Test**: 50 % — холостые обороты вдвое ниже.

### US6 — Батарея питает соседей (P3)
Батарея отдаёт энергию станку вплотную до 256 E/т; кабели и соседние батареи — нет.
**Test**: станок рядом с заряженной батареей получает энергию без кабеля.

## Requirements
- **FR-900** коническое зацепление больших шестерён (d = u·â + v·b̂, ω_B/ω_A = v/u, КПД 0.97).
- **FR-901** пересборка сети по сохранению обобщённого импульса.
- **FR-902** трение подшипника μ·m·g·r (μ 0.0015, m = 2I/r²), трение покоя ×1.5, аэродинамика диска ½C_m ρ ω² r⁵.
- **FR-903** сон сети — только в равновесии (покой или |Δω| < 10⁻⁷·ω).
- **FR-904** клавиша инвентаря закрывает экраны мода (кроме ввода в поле); ответ-обновление не открывает экран.
- **FR-905** напряжение мотора 10–100 %, сохраняется в NBT.
- **FR-906** батарея питает соседние потребители (не кабели и не батареи).

## Success Criteria
- **SC-001** стенд `testPlaytest011` — все 7 проверок; полный стенд зелёный.

## Assumptions
- Малая шестерня под прямым углом не сцепляется (радиус 0.5 блока не достаёт) — для малых и валов есть угловой редуктор.
- Воздух внутри герметичной станции на орбите для аэродинамики роторов не учитывается (профиль тела).
